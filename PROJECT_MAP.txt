🆘 COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════════════════

Problem: build.bat won't run
  → Right-click → Run as administrator

Problem: Python not found
  → Install Python from python.org
  → Check "Add Python to PATH"
  → Restart terminal/command prompt

Problem: PyInstaller not found
  → build.bat installs automatically
  → Or run: pip install pyinstaller

Problem: Build fails
  → Run: pip install pyinstaller yt-dlp

Problem: Can't create installer
  → Install NSIS: https://nsis.sourceforge.io/
  → Then run: create_installer.bat

Problem: App won't start
  → Check FFmpeg is installed: ffmpeg -version
  → User will see helpful error if missing
