# YouTube Video Downloader

This script allows you to download YouTube videos at a specified resolution using `yt_dlp`.

## Dependencies

Before running the script, you need to install the following dependencies:

1. **yt_dlp**: A youtube-dl fork with additional features and fixes.
2. **FFmpeg**: A complete, cross-platform solution to record, convert and stream audio and video.

### Installation

#### yt_dlp

You can install `yt_dlp` using `pip`:

```sh
pip install yt-dlp
```

#### FFmpeg

You can install `FFmpeg` using `winget`:

```sh
winget install "FFmpeg (Essentials Build)"
```

## Usage

Just run the code and input your YT-Video URL.
